Developer Setup & 1-Min Expiry System

Apni app ya website me OTP system lagane ke liye in APIs ka use karein.

1. Send OTP API

Ye API call karne par user ko 4 digit ka OTP jayega. Ye OTP sirf 1 Minute ke liye valid hoga.

METHOD: GET
URL: https://YOUR-RENDER-URL.com/{{ user.username }}/{user_email}

Example: https://YOUR-RENDER-URL.com/{{ user.username }}/test@gmail.com

2. Verify OTP API (Auto Re-send Logic)

User app me OTP dale toh is URL pe POST request bhejein. Agar 1 minute cross ho gaya, toh server khud purana delete karke, naya OTP bhej dega aur response me aapko batayega.

METHOD: POST
URL: https://YOUR-RENDER-URL.com/{{ user.username }}/verify
Headers: Content-Type: application/json
Body:
{
    "email": "test@gmail.com",
    "otp": "1234"
}

// 🟢 SUCCESS RESPONSE:
{ "status": "success", "message": "Account Verified Successfully!" }

// 🟡 1-MIN EXPIRED (AUTO NEW OTP SENT) RESPONSE:
{ "status": "expired_resend", "message": "1 Minute limit over!... NEW OTP to email." }

// 🔴 ERROR RESPONSE:
{ "status": "error", "message": "Invalid OTP entered." }
